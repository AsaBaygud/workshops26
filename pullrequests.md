# How to suggest a change to the contents of a Github repository via a Pull Request | Step-by-step from Claude, reviewed by us

A pull request is made by one person, so each week *one* team member should make it.

1. Create a GitHub account
Go to github.com and sign up. It's free. Confirm your email address. Your username is public, so choose one you're happy for others to see.

2. Open the workshop repo
Go to https://github.com/CompJCDF/workshops26 and click on this week's .md file.

3. Click the pencil icon ✏️ (top right of the file)
GitHub will say you need your own copy to make changes. Click Fork this repository. This makes a copy under your account, so you can't break the original.

4. Make your edits
Type your changes: for workshops this might just be the addition of a URL. The Preview tab shows how the page will look.

5. Save your changes
Click 'Commit changes', write a short note saying what you changed (e.g. "Add our group's notes"), then click Propose changes.

6. Open the pull request
On the next page, click 'Create pull request'. Add a sentence or two explaining your suggestion, then click 'Create pull request' again.

7. Wait for a response
The owner of the repository will review your pull request. They may:

- merge it: your change becomes part of the real file 🎉
- comment to ask for a change: you can edit the file in your fork again, and the pull request updates automatically
- close it without merging
